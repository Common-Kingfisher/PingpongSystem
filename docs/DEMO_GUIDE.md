# 乒乓球赛事编排与赛务管理系统 Demo — 操作手册

## 1. 启动

```bash
# 终端 1：后端（端口 8000）
cd backend
.venv\Scripts\activate            # Windows；首次需先创建 venv 并 pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 终端 2：前端（端口 5173）
cd frontend
pnpm install                      # 首次
pnpm dev
```

浏览器打开 <http://localhost:5173>。

## 2. 准备 Demo 数据（两种方式）

### 方式 A：种子脚本（推荐，一键就绪）

```bash
cd backend
.\.venv\Scripts\python.exe seed_demo.py          # 重建：加 --fresh
```

自动创建「演示赛事（24人/6台）」：24 名选手（选手01~选手24）、6 张球台、
4 组 × 6 人、每组前 2 晋级，并已生成全部 60 场小组赛（待赛状态）。
输出 `id` 后，直接打开 <http://localhost:5173/?tid=<id>。

### 方式 B：手工全流程（演示完整操作路径）

1. **首页**：填写赛事名称/日期/球台数(6)/小组数(4)/每组晋级人数(2) → 创建赛事 → 点击该赛事的「选手与分组」。
2. **选手与分组**：逐个添加 24 名选手（姓名必填）→ 点击「自动分组」→ 查看 A/B/C/D 四组卡片（每组 6 人）→ 点击「生成小组比赛」（提示 60 场）。
3. **比赛控制台**：点「一键调度下一批」把 6 张球台填满 → 在每张球台上输入比分（如 3:1）→「录入比分」→ 再次调度，循环直到 60 场全部完成（顶部统计：已完成 60/60）。
4. **小组排名**：查看四组排名与「✅ 晋级」标记（每组前 2 名，共 8 人）。
5. **淘汰赛**：点「生成淘汰赛（自动晋级）」→ 看到 8 强 4 场 / 半决赛 2 场 / 决赛 1 场。
6. **回到比赛控制台**：继续调度 + 录分打完淘汰赛。
7. **淘汰赛页**：产生 🏆 冠军与亚军，赛事阶段变为 FINISHED。

> 录错比分？在控制台底部「已结束比赛（可修改比分）」点「修改比分」即可，
> 排名与晋级结果会自动整体重算，不会累计污染。

## 3. 页面一览

| 页面 | 地址 | 功能 |
|---|---|---|
| 赛事首页 | `/?tid=` | 赛事信息、阶段、比赛进度条、各页入口；创建赛事、赛事列表 |
| 选手与分组 | `/players?tid=` | 选手增删改查、自动分组、分组结果、生成小组比赛 |
| 比赛控制台 | `/console?tid=` | 进度统计、球台网格（安排/录分/下球台）、一键调度、待赛队列、改分 |
| 小组排名 | `/rankings?tid=` | 四组名次/胜负/净胜局/是否晋级，并列歧义提示 |
| 淘汰赛 | `/knockout?tid=` | 8 强→4 强→决赛树、冠军/亚军 |

## 5. 已知限制（技术债）

- 排名并列：胜场→净胜局→两人交锋后仍无法区分（三人循环等）时，系统**并列标记并
  要求人工裁决**，不编造名次；晋级线附近的并列会导致淘汰赛生成被阻止（409）。
- 淘汰赛仅支持「每组晋级 2 人」且「晋级总人数为 2 的幂（8/16/32）」；其他配置
  明确报错，不支持轮空/种子位。
- 无季军赛（半决赛负者并列四强）。
- 调度为贪心策略（按待赛顺序），非全局最优，不预测时长。
- 小组赛生成后不可重新分组（名单锁定），需 `--fresh` 重建赛事或 ungroup 前置。

## 6. 当前不支持的功能（OUT_OF_SCOPE）

用户注册/登录/权限系统、裁判或选手账号、在线报名、支付、短信/微信通知、
小程序/App、长期积分与全国排名、历史档案、社交、AI 排赛/裁判/视频识别、
云部署/K8s/微服务/Redis/Kafka/ES、复杂规则引擎、种子排名与同单位规避、
手动调整分组、CSV/Excel 导入导出。
