## 3. OpenAPI 冻结范围

冻结文件：`docs/openapi-v0.2.json`
契约版本：`0.2.0`
生成与校验入口：`backend/export_openapi.py`

冻结的 A 侧接口：

- `POST /api/v1/auth/login`
- `POST /api/v1/auth/logout`
- `GET /api/v1/auth/me`
- `POST /api/v1/auth/change-password`
- `GET /api/v1/system/bootstrap/status`
- `POST /api/v1/system/bootstrap`
- `POST /api/v1/system/users`

### 3.1 认证与会话边界

- 浏览器登录成功通过 `Set-Cookie` 建立 `pp_session` 会话，不返回 `access_token`。
- 非浏览器客户端使用 Bearer 不透明令牌，不将该令牌写入 Cookie。
- 同一请求同时携带 Cookie 与 Bearer 且指向不同会话时返回 `401 AUTH_REQUIRED`。
- 账号停用、会话撤销、会话过期或改密后，旧 Cookie/Bearer 均不可继续访问。
- Cookie 固定为 `HttpOnly`、`SameSite=Lax`、`Path=/`；HTTPS 环境追加 `Secure`。
- 当前未开启跨源 credentials；C 轨不得依赖跨源 Cookie。跨源需求必须另行评审 CORS、SameSite、CSRF 与 HTTPS 边界。

### 3.2 Bootstrap 边界

- Bootstrap 状态固定为 `NEEDS_INITIALIZATION`、`READY`、`RECOVERY_REQUIRED`。
- `GET /api/v1/system/bootstrap/status` 只返回分流状态，不返回账号、路径或恢复信息。
- `POST /api/v1/system/bootstrap` 仅允许服务器本机 socket 客户端调用；非本机返回 `404 RESOURCE_NOT_FOUND`。
- 首次初始化以原子事务创建首个 `SYSTEM_ADMIN` 并持久化 `bootstrap_completed=true`。
- 初始化完成后 Web Bootstrap 永久关闭；无可用 `SYSTEM_ADMIN` 时只进入恢复态，不重新开放 Web 写入口。
- 代理头不能将远端请求伪装成本机请求。

### 3.3 权限和错误语义

- `SYSTEM_ADMIN` 管理用户与 Bootstrap，但不因系统角色自动获得赛事业务权限。
- `EVENT_ADMIN` 创建赛事后自动成为 Owner。
- 用户只能读取或管理自己创建、被明确授权的赛事。
- 未登录返回 `401 AUTH_REQUIRED`；系统角色不足返回 `403 FORBIDDEN`；跨赛事资源访问统一返回 `404 RESOURCE_NOT_FOUND`。
- LAN/私网地址只作为部署与传输层，不进入权限模型；来自 LAN 的用户仍按 Cookie/Bearer 和系统角色正常判定。

## 4. C 轨接入说明

C 轨应以冻结后的 `docs/openapi-v0.2.json` 为唯一接口依据：

1. 从该快照生成或校验 TypeScript 类型，不手工复制 A 侧 DTO。
2. 浏览器请求默认走同源或 Vite `/api` proxy；不启用跨源 Cookie。
3. 前端只消费后端返回的允许、只读、无权限结果，不根据角色名称自行推导资源权限。
4. 不根据私网、LAN 或客户端地址推断 `EVENT_ADMIN` 权限。
5. Bootstrap 页面只消费三态状态；写入口仅由服务器本机调用，前端不得绕过或模拟本机身份。
6. 冻结后的字段、状态枚举或错误码如需变化，必须先更新版本化契约和变更说明，再通知 C 轨同步。
7. C 轨需提供 `pnpm build` 和 `pnpm contract:check` 的实际输出证据，才能关闭整体 D2 的前端 Gate。

C 轨相关资料中的“等待 A contract”表述如仍存在，以本报告和 `docs/openapi-v0.2.json` 的实际冻结状态为准；A 轨不修改 C 轨文件。
