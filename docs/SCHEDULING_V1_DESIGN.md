# 比赛时间记录（当前定稿范围）

更新日期：2026-09-09。

## 本期实现

本期不建设赛程预测、休息时间、区域亲和、调度预览、批次确认或官方分钟级秩序册，只增加两个事实字段：

- `matches.started_at`：比赛第一次从 `WAITING` 进入 `PLAYING` 时记录。当前现场流程以确认上台/分配球台作为开赛时间；释放后重新安排不覆盖第一次时间。
- `matches.finished_at`：比赛第一次确认结果并进入 `FINISHED` 时记录。允许从淘汰赛页直接录分的比赛会在同一时刻补齐开始和结束时间。

比分修改、补录逐局小分和裁判备注修改均不得覆盖上述时间。它们有独立的比分审计时间。

历史数据库迁移后允许两个字段为空，页面显示“—”，不根据创建时间或最后修改时间猜测。

## 明确暂缓

- 不增加 `called_at`、预计开赛时间、最短休息时间或调度版本。
- 不建设调度策略、批次和安排审计表。
- 不改变现有手动排台与自动填充空闲球台的方式。
- 不加入现场备份、恢复、一键备份或赛事数据导出入口。
- 官方秩序册模板取得后再单独设计渲染适配。

## 验收

- 首次上台有 `started_at`，释放并重新上台不改变它。
- 首次完赛有 `finished_at`；直接录分时两个时间均存在。
- 修改大比分或补录小比分后，两个时间保持不变。
- OpenAPI、TypeScript 类型、控制台展示和后端测试同步更新。
